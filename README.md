# PetMatch

Сервис, где люди находят питомцев, которым нужен дом. Хозяин публикует анкету питомца, другие пользователи листают ленту и ставят лайки.

## Что реализовано

- Регистрация и вход по email и паролю.
- Добавление питомца: кличка, вид, порода, возраст, описание, фото.
- Лента питомцев других пользователей с кнопками «лайк» и «дизлайк» (также стрелки ← → и перетаскивание карточки). Оценённые питомцы из ленты пропадают; при лайке показывается экран «Это мэтч!».
- Профиль: имя, город, описание и список своих питомцев.
- Вкладка «Чаты» — заглушка, переписка пока не реализована.
- Документация API (Swagger UI) по адресу http://localhost:8080/docs.

## Запуск

Нужны Docker и Docker Compose.

```bash
cp .env.example .env
docker compose up --build
```

Приложение откроется на http://localhost:3000.

Остановка: `docker compose down`. Сброс данных: `docker compose down -v`.
